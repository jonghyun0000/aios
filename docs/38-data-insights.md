# 38 — 공공통계에서 AI 분석으로

## 수정 전 기록 — 2026-09-27

현재 공공통계 상세 화면은 필터·차트·CSV 내려받기를 제공하지만, 선택한 통계와 필터를 채팅으로 넘기는 경로는 없다. 사용자는 통계표 이름·기간·지역·숫자를 다시 입력해야 하며 AI 응답에서 무엇을 근거로 삼았는지도 흐름상 분리된다.

## 사전 완료 기준

1. 통계 상세 화면에서 **AI 분석 초안 만들기**를 누르면 새 채팅으로 이동한다. 선택한 통계명·출처·단위·기간/지역/항목 필터와 수치 요약이 초안에 들어간다.
2. 자동 전송하지 않는다. 사용자는 채팅 입력창에서 내용을 보고 고치거나 지울 수 있다.
3. 원본 통계·프로젝트 파일·DB를 수정하거나 API 키를 URL·저장소에 넣지 않는다. 전달은 같은 출처의 탭 세션 안에서 한 번만 소비한다.
4. 400개 시점 같은 긴 시계열을 그대로 모델에 보내지 않는다. 유효 수치만 쓰고 최근 24개 이하의 표본·시작/끝·최저/최고·관측 수를 명시한다.
5. 결함 주입에서 비유한 수치·빈 제목·과도한 문자열·손상된 전달 객체는 분석 초안이나 채팅 입력으로 채택되지 않아야 한다.
6. 정적 4단계와 웹 단위 검사를 통과한다. 실제 모델 답변의 정확도는 이 기능의 완료 기준이 아니다.

## 범위 밖

AI가 통계를 해석하는 품질, 데이터끼리 자동 비교, 그래프 생성, 외부 웹 검색, 전체 원시 행을 모델에 제공하는 기능은 이번 범위 밖이다. 초안은 분석 요청을 쉽게 시작하게 할 뿐, 출처 전체 검증이나 통계적 인과관계를 보장하지 않는다.

## 최초 결함 주입

- 표본 제외를 초안 문자열의 `"2024-1"` 포함 여부로 확인하자 시작값 요약의 같은 문자열 때문에 실패했다. 표본 배열을 JSON으로 파싱해 길이와 첫·제외 행을 직접 단언하도록 고친다.
- 제어 문자 정리 정규식은 웹 린트의 `no-control-regex` 규칙에 걸렸다. 문자 코드 기반 정리로 바꾸며 NUL·C0·DEL 제거 경계는 유지한다.

## 구현과 검증 — 2026-09-27

`apps/web/src/lib/data-analysis-draft.ts`가 화면에서 이미 불러온 통계만 요약한다. 유효 수치가 없는 통계, 비정상 series ID·빈/과도한 출처 문자열은 초안을 만들지 않는다. 최근 표본은 24개 이하이며, 전체 유효 시점 수·시작/끝·최저/최고는 별도로 남긴다. URL에는 통계값을 넣지 않고 탭의 `sessionStorage`에 한 번 보관한 뒤 채팅 화면이 즉시 삭제·검증한다. 초안은 입력창에만 채워지고 전송 버튼은 사용자가 누를 때까지 모델 요청을 만들지 않는다.

통계 상세 화면의 **AI 분석 초안 만들기**는 선택한 필터를 초안에 넣는다. 분석에는 통계표 이름·기간을 밝히고 수치에 없는 원인을 단정하지 말라는 요청을 포함한다. 이 텍스트는 출처의 완전성·모델의 통계 해석·인과 판단을 보장하지 않는다.
