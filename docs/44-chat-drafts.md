# 44. 대화별 입력 초안 보존 (NEXT_STEPS 5-6)

작성 2026-09-29. §1~§2는 구현 전에 적었다. 사용자 우선순위 4(매일 쓰는 화면: 초안 유실·잘못된 대상 전송)의 첫 항목이다.

## 1. 재현 (실제 Chromium, 키 없는 서버 8792, 새로 만든 대화 두 개)

| 조작 | 입력란 |
|---|---|
| 대화 A에서 "대화 A 에 보낼 긴 초안" 입력 → 대화 B로 이동 | **"대화 A 에 보낼 긴 초안"** — A의 초안이 B에 그대로 있다. 이대로 전송하면 B로 간다 |
| 다시 A로 | 같은 초안 |
| A에서 입력 → 새로고침 | **빈 칸** — 초안 유실 |
| A에서 입력 → 공공통계 화면 → A로 복귀 | **빈 칸** — 초안 유실 |

원인: 입력란은 채팅 화면 하나의 상태(`useState`)이고 대화별로 나뉘지 않으며 어디에도 보관되지 않는다.

## 2. 완료 기준 — 구현 전 등록

1. 초안은 **대화마다 따로** 보관된다. A→B로 가면 B의 초안(없으면 빈 칸)이 보이고, A로 돌아오면 A의 초안이 보인다. 새 대화(대화 선택 전) 초안도 따로다.
2. 새로고침, 다른 화면에 다녀오기, 브라우저를 다시 열기 뒤에도 그 대화의 초안이 돌아온다.
3. 전송이 시작되면 그 대화의 초안을 지운다. 새 대화에서 보내 대화가 생기면 "새 대화" 초안도 지운다. 전송이 시작 전에 실패하면(기존 동작대로 입력란 복원) 초안도 남는다.
4. 보관 한도: 초안 20개, 초안당 50,000자, 7일. 넘는 초안은 가장 오래된 것부터 버린다. 50,000자를 넘는 초안은 저장하지 않고 "이 브라우저에 보관하지 않음"을 알린다. 저장소가 막혀 있거나(사생활 보호 모드 등) 기록이 깨져 있어도 채팅은 정상 동작한다.
5. 초안은 **이 브라우저에만** 있고 서버로 보내지 않는다. 로그아웃하면 모두 지운다.
6. 공공통계 분석 초안·이어서 하기·답변 선호 초기화 문장처럼 입력란을 채우는 기능은 그 대화의 초안으로 보관된다.
   - **정정(구현 중, 2026-09-30):** 이어서 하기 대상이 걸려 있는 동안의 입력은 보관하지 **않는다.** 대상은 새로고침하면 사라지므로, 문장만 남으면 이어서 하기 없이 일반 메시지로 전송된다. 기존 회귀 `chat-goal-flow.spec.ts`(새로고침 뒤 빈 입력란)가 이 충돌을 잡았다.
7. 단위 시험(한도·만료·깨진 기록·저장소 예외) + 실제 Chromium(재현 표의 네 조작 + 전송 후 삭제 + 저장소 예외), 결함 주입, 정적 4단계와 기존 채팅 브라우저 회귀.

## 3. 구현

- `apps/web/src/lib/chat-drafts.ts`: 대화 ID(대화 선택 전은 `new`)별 초안을 localStorage 한 키에 보관. 20개·50,000자·7일 한도, 깨진 기록·저장소 예외는 무시하고 "보관 안 됨"만 알림.
- `apps/web/src/pages/Chat.tsx`: 대화가 바뀌면 그 대화 초안을 불러온다. 입력이 바뀌는 순간 **그 시점의 대화 키로** 저장한다(전환 직후 늦은 저장이 다른 대화에 옮겨 적지 않게). 전송 시작 시 삭제, 시작 전 실패 시 실제 대상 대화로 되살림. 이어서 하기 대상이 걸린 동안은 보관하지 않는다(§2-6 정정).
- `apps/web/src/lib/auth.tsx`: 로그아웃하면 모두 삭제. 서버 변경 없음.

## 5. 같이 발견·수정한 기존 회귀

5-5(`d75065e`)부터 채팅 화면이 `GET /v1/models` 를 조회하는데, 접근성 시험의 합성 API(`e2e/a11y-fixture.ts`)가 이 경로를 몰라 `a11y-workflows.spec.ts` 20건이 "예상 밖 요청"으로 실패했다. **HEAD에서 이번 변경 없이도 재현**했다. 이 시험은 CI `verify-app-a11y.mjs` 에 포함되므로 푸시했다면 CI가 실패했을 것이다. 합성 API에 실제 서버와 같은 모양의 `/v1/models` 응답을 추가해 통과시켰다.

## 6. 한계
- 초안은 브라우저 저장소에 **평문**으로 남는다(같은 컴퓨터 사용자 계정 안). 로그아웃하면 지우지만, 로그아웃하지 않고 창만 닫으면 7일 동안 남는다.
- 같은 대화를 두 탭에서 동시에 편집하면 마지막으로 입력한 탭의 초안이 남는다.
- 실제 스크린리더 청취는 하지 않았다.
- 시험 중 Mac 재부팅으로 Colima가 꺼져 있어 `colima start` 와 `dev-up.sh` 로 개발 DB를 기동했다(기존 볼륨 그대로, 삭제 없음). 사용자 시작기(8791)는 켜지 않았다.
